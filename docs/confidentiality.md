# Confidentiality & Masking Policy

This repository distills carrier-grade telecom engineering experience into **generic, reusable tooling and templates**. It intentionally contains **no proprietary or confidential material**.

## What this repository does NOT contain

- **No real network configurations** — no configs from any operator's production network (all samples are synthetic, with invented hostnames, IPs and parameters).
- **No internal company documents** — no procedures, ATPs, MOPs or reports from any former employer.
- **No vendor documentation** — no copyrighted manuals, guides or release notes from network vendors (Huawei, Ericsson, ZTE, Nokia...). Vendor rights are respected.
- **No credentials or infrastructure data** — no IPs, hostnames, connection strings, keys or Topology/location data of real networks.

## How the templates were built

The templates in `examples/` (MOP, ATP) and the synthetic configuration sample follow **industry-standard structure and practice** — the same structure used across the telecom industry — but contain only invented placeholder values. They demonstrate domain knowledge, not confidential content.

## For former colleagues and employers

If you believe any content here references confidential material, please [open an issue](https://github.com/maezgonz/telco-network-automation/issues) and it will be reviewed and removed promptly.
